# Department of Everything

A playful ward management game for Windows by xo-Vendetta. You run the Department of Everything for Ward 1, a
district of the Central Ark: its people work, eat, sleep and travel by themselves, and you decide what is built and how
the ward's work is run. The ward keeps your PC's time, even while the game is closed.

## Download

Get the latest installer from **[Releases](https://github.com/xo-Vendetta/department-of-everything-releases/releases/latest)**
(`DepartmentOfEverything_<version>_x64-setup.exe`) and run it. From version 0.2.0 on, the game tells you when a new
version is out and updates itself when you say so.

Windows may show **"Windows protected your PC"** the first time, because the installer isn't code-signed. Click
**More info → Run anyway**.

## Notes

- This is a playtest (Prototype 1), so expect rough edges.
- Your ward is saved on your own PC. The game's only connection is its check for a new version, on this page. Nothing
  about you or your ward is sent.
- Every update is signed, and the game installs only updates signed with its own key.
- This repository only hosts installers. The source code is private.
